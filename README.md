# 🎬 MovieCity - Landing Page em React

A **MovieCity** é uma *Landing Page* moderna e responsiva desenvolvida em **React** utilizando o **Vite** como ferramenta de construção (*build tool*). O objetivo principal deste projeto é aplicar e consolidar os fundamentos básicos do ecossistema React, desde a componenteização até ao design adaptável para múltiplos ecrãs.

---

## 💡 Conhecimentos e Objetivos Abordados

Nesta atividade foram trabalhados os seguintes conceitos essenciais:

- ⚡ **Criação e Execução com Vite:** Configuração e inicialização rápida de um projeto React.
- 📁 **Estruturação do Projeto:** Organização clara e modular de pastas, ficheiros e recursos.
- 🧩 **Criação de Componentes:** Divisão da interface em componentes reutilizáveis e de fácil manutenção.
- 🖼️ **Carregamento de Imagens:** Gestão e exibição otimizada de recursos visuais estáticos e dinâmicos.
- 📱 **Responsividade:** Adaptação da interface a diferentes resoluções e tamanhos de ecrã (Mobile, Tablet e Desktop).

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** — Biblioteca para construção de interfaces de utilizador.
- **[Vite](https://vitejs.dev/)** — Ferramenta de desenvolvimento rápida para aplicações web modernas.
- **JavaScript (ES6+)** — Linguagem de programação base.
- **CSS3 / HTML5** — Estruturação e estilização da página.
- **ESLint** — Padronização e garantia de qualidade do código.

🚀 Como Executar o Projeto
Pré-requisitos
Certifique-se de que tem o Node.js (versão 16 ou superior) instalado no seu computador.

Passo a Passo
Aceder à pasta do projeto:

Bash
cd React/01_landinpage
Instalar as dependências:

Bash
npm install
Iniciar o servidor de desenvolvimento:

Bash
npm run dev
Visualizar no navegador:
Aceda ao endereço indicado no terminal (normalmente http://localhost:5173/).

🧪 Testes e Validação
Para garantir o cumprimento dos requisitos da proposta, foram realizados os seguintes testes:

Testes de Execução: Validação da compilação sem erros através do Vite.

Fidelidade Visual: Comparação do resultado final com o layout e capturas de ecrã fornecidos no roteiro.

Teste de Responsividade: Verificação do comportamento da página em diferentes dispositivos (smartphones, tablets e monitores).
